# 每日健康记录（手机可安装版）

## 包含功能
- 按日期记录经期、早晚体重和体温、多次排便、三餐食物及重量、每日便签
- 自动本地保存（浏览器 localStorage）
- CSV 导出（Excel 可打开，含 UTF-8 BOM）
- JSON 完整备份与恢复
- 最近 7 天 / 本月汇总报告
- Service Worker 离线缓存
- PWA manifest，可添加到安卓手机桌面并以独立窗口运行

## 安装到安卓手机
1. 将本文件夹中的所有文件部署到支持 HTTPS 的静态网站托管服务。
2. 用安卓 Chrome 打开部署后的 `https://...` 地址。
3. 点击右上角 ⋮，选择“安装应用”或“添加到主屏幕”。
4. 安装后从手机桌面图标打开。

注意：仅把 ZIP 解压到手机并直接打开 index.html，不能完成标准 PWA 安装；Service Worker 和安装功能需要 HTTPS（localhost 开发环境除外）。

## 数据与隐私
记录默认只存放在当前浏览器本地，不会自动同步到其他设备。清除浏览器网站数据、卸载/更换浏览器或手机可能导致数据丢失，请定期在“数据管理”中导出 JSON 备份。CSV 适合用 Excel 查看；JSON 用于完整恢复。

## 健康提示边界
趋势报告是对已填写数据的简单汇总，不是医学诊断。食物名称与重量输入较粗略，不能精确计算营养素；如需精确营养分析，需逐项记录食材重量和烹饪方式。
